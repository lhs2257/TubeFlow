이전 세션의 맥락을 복원하고 현재 상태를 파악합니다.

다음 절차를 순서대로 수행하세요:

1. **PROGRESS.md 읽기**: 전체 작업 현황 파악
2. **git log --oneline -15**: 최근 커밋 이력으로 작업 흐름 확인
3. **git status**: 커밋되지 않은 변경사항 확인
4. **git diff --stat HEAD~3..HEAD**: 최근 3개 커밋의 변경 파일 범위 파악
5. **PROJECT.md 읽기**: 프로젝트 구조 및 규칙 확인

위 정보를 종합하여 다음 형식으로 보고하세요:

```
현재 상태: (진행중/완료/대기 작업)
미커밋 변경: (있음/없음)
다음 작업: (PROGRESS.md 기준)

```
