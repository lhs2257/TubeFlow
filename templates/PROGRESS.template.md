# 작업 현황 (PROGRESS)

> 이 문서는 프로젝트의 전체 진행 상황을 실시간으로 추적합니다.
> **모든 작업 완료 시 반드시 이 문서를 업데이트해야 합니다.**

## 전체 진행률

**[0/N] 완료** | 현재 단계: [단계명]

범례: [x] 완료 | [>] 진행 중 | [ ] 대기 | [-] 건너뜀
