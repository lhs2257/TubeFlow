# references/01-design/ - 디자인 시안

## 용도

UI/UX 디자인 시안, 와이어프레임, 화면 레이아웃 참조 자료를 보관합니다.

## 파일 배치 안내

Figma 내보내기, 손그림 스캔, 스크린샷 등을 이 폴더에 넣어주세요.

예시:
```
01-design/
├── wireframe-main.png       # 메인 화면 와이어프레임
├── wireframe-sourcing.png   # 소재 수집 탭
├── wireframe-script.png     # 대본 작성 탭
├── wireframe-uploader.png   # 업로드 탭
└── wireframe-trend.png      # 트렌드 분석 탭
```

## 주의사항
