[핵심 규칙 리마인더 - 매 작업 시 반드시 준수]
1. 파일 수정 후 -> PROGRESS.md와 관련 README.md를 반드시 업데이트
2. 작업 완료 후 -> 사용자에게 다음 단계 승인을 반드시 요청 (자동 진행 금지)
3. 모듈 경계 -> 현재 작업 중인 모듈 외 파일 수정 금지
4. 이모지 금지 -> 텍스트 마커 사용: [완료], [진행중], [대기], [주의], [중요]
5. 문서 품질 -> 격식체(합쇼체), H2~H3만 사용, 코드 블록 언어 지정
6. 인코딩 -> UTF-8(BOM 없음), 한글 경로 큰따옴표 감싸기
7. 하나의 작업에만 집중 -> 병렬 작업 금지, 순차 실행
